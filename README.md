# Jogo de Adivinhação

Este projeto é uma implementação simples e divertida do clássico jogo de adivinhação, criado com o objetivo de praticar conceitos básicos de JavaScript, HTML e CSS.

## Objetivo

O jogo desafia o usuário a descobrir um número secreto entre 1 e 100. A cada tentativa, o jogador recebe uma dica se o número é maior ou menor, até acertar.

## Tecnologias utilizadas

- HTML: estrutura da interface do jogo
- CSS: estilização moderna, com tema visual inspirado em jogos
- JavaScript: lógica do jogo, controle de tentativas e interatividade

## Funcionalidades

- Campo para digitar o palpite
- Feedback instantâneo após cada tentativa
- Contagem de tentativas
- Botão para reiniciar o jogo
- Efeito visual de comemoração ao acertar

## Como executar

1. Abra o arquivo HTML no navegador
2. Ou utilize um servidor local simples, como o Live Server

Este projeto é ideal para quem está começando a desenvolver páginas interativas com JavaScript.
